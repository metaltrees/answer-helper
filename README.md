# Social Intelligence Test

A psychological test-style web application that evaluates social intelligence through real-world scenarios and provides AI-powered personalized advice.

## 🎯 Features

- **10 Scenario-Based Questions**: Real-world situations across workplace, social, and family contexts
- **Progress Tracking**: Visual progress bar showing completion status
- **AI-Powered Analysis**: Personalized insights generated by Amazon Bedrock (Claude)
- **Mobile Responsive**: Works on all devices
- **No Login Required**: Instant access, privacy-focused

## 🚀 Deployment Guide

### Part 1: Deploy Frontend to GitHub Pages

#### Step 1: Create GitHub Repository
```bash
# Initialize git in your project folder
cd social-intelligence-test
git init

# Add all files
git add .
git commit -m "Initial commit: Social Intelligence Test"

# Create repo on GitHub, then:
git remote add origin https://github.com/YOUR_USERNAME/social-intelligence-test.git
git branch -M main
git push -u origin main
```

#### Step 2: Enable GitHub Pages
1. Go to your repository on GitHub
2. Click **Settings** → **Pages**
3. Under "Source", select **Deploy from a branch**
4. Select **main** branch and **/ (root)** folder
5. Click **Save**
6. Your site will be live at: `https://YOUR_USERNAME.github.io/social-intelligence-test/`

---

### Part 2: Deploy Backend to AWS

#### Step 1: Create IAM Role for Lambda

1. Go to **AWS Console** → **IAM** → **Roles** → **Create role**
2. Select **Lambda** as the trusted entity
3. Attach these policies:
   - `AWSLambdaBasicExecutionRole` (for CloudWatch logs)
4. Create an inline policy with Bedrock permissions:

```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": "bedrock:InvokeModel",
            "Resource": "arn:aws:bedrock:*::foundation-model/anthropic.*"
        }
    ]
}
```

5. Name the role: `SocialIntelligenceTestLambdaRole`

#### Step 2: Create Lambda Function

1. Go to **AWS Console** → **Lambda** → **Create function**
2. Configure:
   - **Function name**: `SocialIntelligenceTestAnalyzer`
   - **Runtime**: Python 3.11
   - **Architecture**: x86_64
   - **Execution role**: Use the role created above

3. Upload the code:
   - Copy contents of `backend/lambda_function.py` into the Lambda editor
   - Or zip and upload: `zip -r function.zip lambda_function.py`

4. Configure settings:
   - **General configuration** → **Timeout**: 30 seconds
   - **General configuration** → **Memory**: 256 MB

5. Add environment variable (optional):
   - `MODEL_ID`: `anthropic.claude-3-haiku-20240307-v1:0`

#### Step 3: Create API Gateway

1. Go to **AWS Console** → **API Gateway** → **Create API**
2. Choose **REST API** → **Build**
3. Configure:
   - **API name**: `SocialIntelligenceTestAPI`
   - **Endpoint Type**: Regional

4. Create resource and method:
   - **Actions** → **Create Resource**
   - **Resource Name**: `analyze`
   - **Resource Path**: `/analyze`
   
5. Add POST method:
   - Select `/analyze` → **Actions** → **Create Method** → **POST**
   - **Integration type**: Lambda Function
   - **Lambda Function**: `SocialIntelligenceTestAnalyzer`
   - Enable **Lambda Proxy integration**

6. Enable CORS:
   - Select `/analyze` → **Actions** → **Enable CORS**
   - Check all boxes, click **Enable CORS and replace existing CORS headers**

7. Deploy API:
   - **Actions** → **Deploy API**
   - **Deployment stage**: Create new stage named `prod`
   - Note your **Invoke URL**: `https://xxxxxxxx.execute-api.us-east-1.amazonaws.com/prod`

#### Step 4: Update Frontend with API Endpoint

Edit `js/app.js` and update these lines:

```javascript
const CONFIG = {
    TOTAL_QUESTIONS: 10,
    API_ENDPOINT: 'https://YOUR_API_ID.execute-api.YOUR_REGION.amazonaws.com/prod/analyze',
    USE_MOCK_API: false  // Change to false to use real API
};
```

Commit and push the changes to GitHub.

## 🔧 Customization

### Adding More Questions
Edit `js/situations-db.js` and add scenarios following this format:

```javascript
{
    id: "work006",
    category: "workplace",
    situation: "Your situation description here...",
    options: [
        "Option A text",
        "Option B text", 
        "Option C text"
    ],
    correctIndex: 1,  // Index of the optimal answer (0, 1, or 2)
    traits: {
        assertiveness: [0, 2, 1],  // Score for each option
        communication: [1, 2, 0]
    }
}
```

### Changing the AI Model
In Lambda environment variables, change `MODEL_ID` to:
- `anthropic.claude-3-sonnet-20240229-v1:0` (Better quality, higher cost)
- `anthropic.claude-3-haiku-20240307-v1:0` (Faster, lower cost)
